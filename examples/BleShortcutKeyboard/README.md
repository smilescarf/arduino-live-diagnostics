# 11 · 三按键 BLE 复制粘贴剪切键盘

只在实体按键按下后发送 Ctrl+C、Ctrl+V、Ctrl+X，并自动松开；先在空白文本编辑器中测试。

## 实验准备

- 板型：ESP32-S3；Arduino-ESP32 3.x（已用 3.3.12 编译验证）
- 当前选择：esp32:esp32:esp32s3
- 所需库：仅使用开发板核心自带 API / 库
- 接线：3 个按键分别接 GPIO39、40、41 与 GND；内部上拉。通过电脑系统蓝牙设置配对 ArduinoLab-Keys。
- 参数：KEY_PINS = {39,40,41}；CTRL_MODIFIER = 0x01（Windows/Linux）

## 操作与观察

1. 断电接线，核对电源、地线和引脚编号，按模块实际规格供电。
2. 在 IDE 中选择实际开发板；安装上列依赖；修改代码顶部参数。
3. 打开实时监测面板观察编辑中的错误；运行硬件实验仍需点击上传。
4. 只在实体按键按下后发送 Ctrl+C、Ctrl+V、Ctrl+X，并自动松开；先在空白文本编辑器中测试。

## 排错

- 无法编译：核对开发板、核心版本与依赖；以第一条错误为起点。
- 无串口输出：监视器设为 115200；ESP32-S3 的 USB CDC 设置按实际连接方式选择。
- 编译通过但器件无反应：核对共地、引脚、电平、有效高低电平与模块型号。
- 使用 ESP32 核心内置 BLEHIDDevice 实现同一作业，避免旧版 ESP32-BLE-Keyboard 的核心兼容问题；支持配对的主机系统仍须实机验证。更改报告后系统可能需要删除旧配对再连接。
