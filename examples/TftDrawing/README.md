# 08 · ST7789 图形与文字

显示文字、圆和直线；每秒在底部更新计数。

## 实验准备

- 板型：ESP32-S3；Arduino-ESP32 3.x（已用 3.3.12 编译验证）
- 当前选择：esp32:esp32:esp32s3
- 所需库：LovyanGFX（Arduino IDE → 库管理器安装）
- 接线：240×320 ST7789：3.3V、GND、SCK12、MOSI11、DC14、CS10、RST4；背光按模块额定电流供电，勿由普通 GPIO 直接供大电流。
- 参数：SCK=12 MOSI=11 DC=14 CS=10 RST=4；panel_width=240 panel_height=320

## 操作与观察

1. 断电接线，核对电源、地线和引脚编号，按模块实际规格供电。
2. 在 IDE 中选择实际开发板；安装上列依赖；修改代码顶部参数。
3. 打开实时监测面板观察编辑中的错误；运行硬件实验仍需点击上传。
4. 显示文字、圆和直线；每秒在底部更新计数。

## 排错

- 无法编译：核对开发板、核心版本与依赖；以第一条错误为起点。
- 无串口输出：监视器设为 115200；ESP32-S3 的 USB CDC 设置按实际连接方式选择。
- 编译通过但器件无反应：核对共地、引脚、电平、有效高低电平与模块型号。
- 默认 SPI 40MHz、mode0，与课件示例一致选择 mode0 并降低频率；花屏先查接线和模块规格，再调速率、偏移与反色。
