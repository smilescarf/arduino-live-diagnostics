# 06 · WS2812 六种灯效与往返彗星

EFFECT：0三色轮换、1彩虹、2彗星、3往返彗星、4呼吸、5随机闪烁。

## 实验准备

- 板型：ESP32-S3；Arduino-ESP32 3.x（已用 3.3.12 编译验证）
- 当前选择：esp32:esp32:esp32s3
- 所需库：FastLED（Arduino IDE → 库管理器安装）
- 接线：8 灯 WS2812 数据接 GPIO7（串 330Ω），共地；供电按灯带规格，5V 灯带用外部电源和合适的 3.3V→5V 数据电平转换。勿由 GPIO 供电。
- 参数：DATA_PIN = 7；NUM_LEDS = 8；EFFECT = 0～5；BRIGHTNESS = 32

## 操作与观察

1. 断电接线，核对电源、地线和引脚编号，按模块实际规格供电。
2. 在 IDE 中选择实际开发板；安装上列依赖；修改代码顶部参数。
3. 打开实时监测面板观察编辑中的错误；运行硬件实验仍需点击上传。
4. EFFECT：0三色轮换、1彩虹、2彗星、3往返彗星、4呼吸、5随机闪烁。

## 排错

- 无法编译：核对开发板、核心版本与依赖；以第一条错误为起点。
- 无串口输出：监视器设为 115200；ESP32-S3 的 USB CDC 设置按实际连接方式选择。
- 编译通过但器件无反应：核对共地、引脚、电平、有效高低电平与模块型号。
- 默认亮度降低；课件中的 FastLtED、voidsetup、尾随 ar 拼写错误已修正。
