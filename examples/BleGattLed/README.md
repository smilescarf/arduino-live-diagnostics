# 11 · GATT 控灯与传感器通知

向 LED 特征写入文本 1/0 控灯；订阅传感器特征后每 2 秒收到 ADC 原始值；READ 也能读取。

## 实验准备

- 板型：ESP32-S3；Arduino-ESP32 3.x（已用 3.3.12 编译验证）
- 当前选择：esp32:esp32:esp32s3
- 所需库：仅使用开发板核心自带 API / 库
- 接线：LED41 经电阻接地；可选电位器中间脚接 GPIO1，两端 3.3V/GND；手机使用 BLE 调试工具。
- 参数：LED_PIN = 41；ADC_PIN = 1；SENSOR_UUID / LED_UUID

## 操作与观察

1. 断电接线，核对电源、地线和引脚编号，按模块实际规格供电。
2. 在 IDE 中选择实际开发板；安装上列依赖；修改代码顶部参数。
3. 打开实时监测面板观察编辑中的错误；运行硬件实验仍需点击上传。
4. 向 LED 特征写入文本 1/0 控灯；订阅传感器特征后每 2 秒收到 ADC 原始值；READ 也能读取。

## 排错

- 无法编译：核对开发板、核心版本与依赖；以第一条错误为起点。
- 无串口输出：监视器设为 115200；ESP32-S3 的 USB CDC 设置按实际连接方式选择。
- 编译通过但器件无反应：核对共地、引脚、电平、有效高低电平与模块型号。
- 写入格式为 UTF-8/文本字符 1 或 0（十六进制 31/30），不是二进制 01/00；先订阅通知。全部使用自定义 128 位 UUID。
