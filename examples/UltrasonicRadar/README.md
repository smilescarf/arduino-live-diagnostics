# 08 · 舵机超声波雷达与近距报警

每次舵机移动后等待稳定，再输出角度/距离；近于 20cm 点亮 LED。

## 实验准备

- 板型：ESP32-S3；Arduino-ESP32 3.x（已用 3.3.12 编译验证）
- 当前选择：esp32:esp32:esp32s3
- 所需库：ESP32Servo（Arduino IDE → 库管理器安装）
- 接线：超声波 Trig→GPIO5、Echo→GPIO6，共地。按模块规格供电；5V Echo 必须经过分压/电平转换到 ESP32 允许的电平。 舵机信号4、独立5V供电且共地；LED41 串电阻接地。
- 参数：SERVO_PIN = 4；SCAN=30～150°；ALARM_CM = 20

## 操作与观察

1. 断电接线，核对电源、地线和引脚编号，按模块实际规格供电。
2. 在 IDE 中选择实际开发板；安装上列依赖；修改代码顶部参数。
3. 打开实时监测面板观察编辑中的错误；运行硬件实验仍需点击上传。
4. 每次舵机移动后等待稳定，再输出角度/距离；近于 20cm 点亮 LED。

## 排错

- 无法编译：核对开发板、核心版本与依赖；以第一条错误为起点。
- 无串口输出：监视器设为 115200；ESP32-S3 的 USB CDC 设置按实际连接方式选择。
- 编译通过但器件无反应：核对共地、引脚、电平、有效高低电平与模块型号。
- 串口输出 cm=-1 表示超时；pulseIn 最长阻塞 25ms。
